娘化角色鼠标指针 · 全套 15 个 — 使用说明
=============================================

【当前状态：已直接应用到系统，动动鼠标就能看到整套效果】

指针一览（全套 17 个，含 Win11 新角色）
--------
正常选择 / 链接选择 / 帮助选择   角色贴纸 + 左上角小三角（热点=三角尖端）
忙 / 后台运行 / 不可用           角色特写 / 带星星 / 带红圈
精确选择 / 文本选择              蝴蝶结十字 / I 形梁 + 角色探头
手写 / 备用选择                  小铅笔 / 独立大箭头
上下·左右·对角调整 / 移动        圆角双箭头 / 四向箭头
位置选择 / 个人选择              小手 + 定位徽章 / 小手 + 人形徽章

调大小
------
设置 → 辅助功能 → 鼠标指针和触控 → 「大小」滑块往右拉（最大 256px）。

恢复默认
--------
Win+R 输入 main.cpl 回车 →「指针」选项卡 → 方案选「Windows 默认（系统方案）」→ 确定。

重新安装 / 装到别的电脑
----------------------
右键「安装鼠标指针.inf」→「安装」，再 Win+R 运行 main.cpl →「指针」→
方案选「MoeCursor」→ 确定。
（INF 已包含全部 15 个指针的注册；如果之前装过旧版，重新安装一次即可覆盖）

文件
----
moe_*.cur          15 个指针文件（32-256 多档尺寸，32位透明）
安装鼠标指针.inf   一键安装脚本
效果预览.png       整套预览图
build_v4.py        生成脚本（想改颜色/图案就改它再重跑）
